# @studyzy/dsh-client-ui-suggest-prompt

[English](README.md) | 中文

建议提示词表面的浏览器半边：一个 `conversation.input.dock` 桥接条目，读取 `suggestPrompt` 会话投影，通过 `inputActions.setGhost` 将当前建议推入输入框的幽灵装饰。草稿为空时，输入框将幽灵渲染为占位文本。

在输入框 textarea 持有焦点时按下配置的快捷键（默认 **Tab**，与 Claude Code 一致）接受建议；文本会填入草稿（可编辑）而非直接发送。快捷键来自宿主插件在每条建议上携带的 `acceptKey` 配置——例如 `Tab`、`Alt+Slash` 或 `Ctrl+Enter`。

## 行为

- 仅当建议对应会话最近完成的回合、agent 空闲且草稿为空时显示幽灵文本。
- 接受快捷键仅在焦点位于 textarea 时生效；IME 组合输入期间的按键不会触发，且只有在显示幽灵时才会拦截 Tab（否则保留其默认焦点行为）。
- 输入会清除幽灵；删除回空草稿会从持久化投影重新武装它，无需新的模型调用。
- 条目本身不渲染任何内容；所有效果都作用在输入机状态上。

## 模型体验

不涉及，本插件仅消费宿主计算的 `suggestPrompt` 投影并将其渲染为输入框幽灵文本；这里没有任何内容会到达模型请求。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- 接受快捷键仅在焦点位于 textarea 时生效；某些键盘布局可能将配置的按键路由到其他地方。
- 快捷键无法仅从浏览器侧配置——需要通过宿主插件的 `acceptKey` 配置设置，并随每条建议事件下发。
